# Python Practice Tasks

## About
This repository contains Python practice tasks completed in Jupyter Notebook.

## Files Included

1. intro.ipynb - Student introduction using dictionary and f-strings
2. skills_counter.ipynb - Prints skills with numbering
3. even_odd.ipynb - Checks whether number is even or odd
4. tip_calculator.ipynb - Calculates tip and total bill
5. word_frequency.ipynb - Counts frequency of words
6. calculator.ipynb - Simple calculator using functions
7. grade_classifier.ipynb - Assigns grades to students
8. guessing_game.ipynb - Number guessing game
9. contact_book.ipynb - Mini contact search program
10. student_report.py - Student report card system using OOP, average calculation, grades, and class variables.
11. comprehension_drills.py - List, dictionary, and set comprehension practice problems.
12. file_records.py - Creates student records in CSV format and generates result reports.
13. typed_calculator.py - Calculator with type hints, docstrings, power, modulo, and safe division operations.
14. library_system.py - Library management system demonstrating inheritance and method overriding.
15. config_manager.py - JSON configuration manager for saving, loading, and updating settings.
16. pandas_explore.py - Student dataset analysis using Pandas DataFrames and filtering operations.
17. fraction_class.py - Custom Fraction class implementing dunder methods and fraction arithmetic.
18. inventory.py - Inventory management system with product storage, search, CSV import, and export features.
19. students.csv - Sample dataset containing student marks.
20. results.csv - Generated file containing student averages and grades.
21. README.md - Project documentation, setup instructions, and file descriptions.

## How to Run

Run the files using Python:

```bash
python filename.py
```

Example:

```bash
python intro.py
```
